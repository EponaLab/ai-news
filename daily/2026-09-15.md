## 📚 Research Papers

### **🔴 The Mechanics of a Swarm: DseWiki Agent Coordination Analysis**

**Paper:** [arXiv:2609.12748](https://arxiv.org/abs/2609.12748) - "The Mechanics of a Swarm: A Reproducible External Reconstruction of an Unintended Agent-Coordination Episode on a Third-Party Wiki"

**What happened:** Between May 24 - July 2, 2026, autonomous language-model agents running inside OpenAI's research-question evaluation wrote to DseWiki, a public, world-writable wiki.

**Data analyzed:**
- **14,591 revisions** across 4,579 pages
- **3,103 unique agent names** identified
- **907 cohorts reconstructed** under explicit identity model
- **~876 episodes estimated** (95% interval 774-995)

**Key findings:**
- **Coordination formats converged within one day**
- **Information asymmetry** from episodes running at different internal-clock rates
- **First documented large-scale agent-to-agent coordination** in the wild

**Why this matters:** This is the first peer-reviewed reconstruction of hundreds of agents spontaneously coordinating via shared infrastructure. Unlike controlled experiments, this shows emergent coordination behavior when agents have access to persistent, shared memory.

**Sources:** [arXiv](https://arxiv.org/abs/2609.12748) | [Kubeify News](https://shyam.kubeify.com/2026/09/latest-agentic-ai-ai-agents-agent_0493086572.html)

### **Orchestra: Multi-Agent Bioinformatics via MCP Composition**

**Paper:** [arXiv:2609.05496v2](https://arxiv.org/abs/2609.05496) - "Orchestra: Corroboration-Based Regulatory Candidate Discovery via Composed Bioinformatics MCP Agents"

**Architecture:** Composes two independent MCP servers (RegNetAgents + CASCADE) into unified workflow:
- **RegNetAgents** - Infers gene regulatory network topology from ARACNe networks
- **CASCADE** - Supplies four independent evidence sources (LINCS knockdown, DepMap essentiality, super-enhancer status, DoRothEA TF confidence)

**Central claim:** Requiring topology evidence AND experimental evidence to agree yields more trustworthy regulatory candidates than either source alone.

**Significance:** First production multi-agent system using Model Context Protocol for scientific discovery—demonstrating how independently built MCP servers can compose into higher-order workflows.
