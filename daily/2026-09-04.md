## 📚 Research Papers

**1. Repo-To-Skill: Distilling GitHub Repositories Into AI4AI Skills (arXiv:2609.02749)**

Posted September 2, introduces **DisCo**, a framework that automatically distills operational knowledge from GitHub repositories and scientific papers into structured, verifiable skill graphs. The method boosts GPT-5.5 agent performance by +134.3% on MLE-bench by packaging repository know-how as reusable skills rather than requiring agents to rediscover implementation details on every run. This addresses a critical gap in autonomous ML research agents: the need for operational knowledge (how to actually run code) beyond conceptual understanding. [arXiv](https://arxiv.org/html/2609.02749) | [Hugging Face Papers](https://huggingface.co/papers/2609.02749) | [AI Weekly Analysis](https://aiweekly.co/editors-blog/found-first-repo-to-skill-5-000-github-distilled-skills-push-a-gpt-5-5-agent-134)

**2. Decoupling Planning and Control for Instructable Agents (arXiv:2608.26788)**

Published at COLM 2026, this paper explores architectural patterns that separate high-level planning from low-level control in instructable agents, enabling more robust multi-agent coordination. [arXiv Multiagent Systems](https://arxiv.org/list/cs.MA/recent)

**3. Agent Composition and Creativity Research**

Recent work highlights that agent system outcomes depend on composition: which agents are present, in what proportion, and how they are connected. The research explores how individual AI gains can accumulate without eroding collective diversity. [Papers.cool](https://papers.cool/arxiv/cs.AI)

## 💡 Insights & Analysis

**The AGI Narrative Accelerates**

OpenAI's positioning of GPT-6 Astra as entering the "AGI era" marks a significant shift in industry rhetoric. While "AGI" remains contentious and poorly defined, the framing signals confidence in step-function capability improvements, particularly in agentic tasks and computer operation. The delayed release (originally planned earlier but postponed after July 2026 Hugging Face breach) suggests security and alignment concerns are now first-order constraints on frontier model launches.

**Security Infrastructure Becomes Table Stakes**

This week's $127M in AI security funding (HiddenLayer + Huskeys) confirms that security is no longer a post-deployment consideration but a prerequisite for enterprise agent adoption. The emergence of distinct security categories—runtime protection (HiddenLayer), attack traffic filtering (Huskeys), identity/access (Ping, Okta)—mirrors the maturation of cloud security infrastructure in the 2010s. Enterprises won't scale agents without these foundational security layers.

**The Skill Graph Revolution**

The Repo-To-Skill/DisCo framework represents a potential paradigm shift in how agents acquire capabilities. Rather than agents learning by trial-and-error on every task, distilling operational knowledge into verified, reusable skill graphs could dramatically improve reliability and efficiency. The +134% performance gain on MLE-bench suggests this approach may be key to moving agents from research curiosities to production workhorses.

**Production Remains the Hard Part**

Despite 80% of enterprise apps now embedding agents, only 31% run in production and just 10% reach scale. The gap isn't capability—it's governance, orchestration, observability, and ROI measurement. Gartner's forecast that 40%+ of agentic projects will fail by 2027 reflects this infrastructure debt. Winners will be those who solve the operational challenges, not just the technical ones.

**The Governance-First Era Solidifies**

Every major announcement this week reinforces the shift from "agents first, governance later" to "governance enables agents." Ping Identity's personal agent controls, HiddenLayer's runtime security, Adobe's governed marketing workflows—all position governance as a competitive advantage, not a compliance checkbox. The 60% of enterprises running agents without formal governance face escalating risk as agent autonomy increases.
