## 🔥 Key Highlights

### 1. AWS Freezes Bedrock Agents Classic, Pushes AgentCore Migration

**Impact: ★★★★★ | Infrastructure Consolidation**

**What changed:** Amazon renamed its Bedrock Agents service to **Bedrock Agents Classic** and, as of **July 30, 2026**, closed it to new customers while allowlisted accounts retain full access with no announced end-of-life date. The change blocks only two API calls for non-allowlisted accounts—`CreateAgent` and `InvokeInlineAgent`—and freezes the Classic model catalog as of July 30, 2026, meaning newly released foundation models will not appear inside the Classic orchestration layer. **AgentCore** remains a separate, framework-agnostic runtime with dedicated services for runtime, gateway, memory, identity, and observability, positioned as the path forward for new production agents.

**Why it matters:** 
- **Existing deployments safe:** Teams already running Bedrock Agents Classic can continue indefinitely, but won't see new models
- **Future-proofing required:** New projects must use AgentCore to access latest models and features
- **Strategic shift:** AWS consolidating from dual-track to AgentCore-first architecture
- **Migration window:** No hard deprecation timeline announced, but innovation stopped on Classic stack

**For enterprises:** Audit which workloads depend on Classic, document agents and models in use, and begin testing equivalent flows on AgentCore to avoid future migration pressure.

### 3. Enterprise Security Product Wave: 8 Major Launches in 24 Hours

**Impact: ★★★★★ | Security Infrastructure Maturation**

**Context:** In the 48 hours following XBOW's autonomous Bing RCE discoveries (Wednesday) and shadow evaluation results showing agent engineering prowess (Thursday), the security industry shipped **eight production-ready security products** specifically designed for agentic AI governance. #### **A. Cequence Extends Agentic Zero-Trust Controls**

**What launched:** Four new AI Gateway capabilities—**AI Discovery**, **API Registry**, **LLM Registry**, and **Skill Registry**—plus upgraded **Agent Personas** that bind an agent's job description directly to its model, tools, and guardrails.

**Key features:**
- **AI Discovery:** Surfaces every agent, AI provider, and MCP server already running from security logs
- **API Registry:** Lets agents call approved APIs without ever holding raw credentials
- **Agent Personas:** Non-technical stakeholders define agent scope; gateway enforces automatically
- **Least-privilege by default:** Agents get minimum access required for their defined role

**Why it matters:** Security teams can find shadow agents already in production, standardize API access, and enforce policies without requiring business users to understand security tooling.

**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)

#### **B. Bedrock Data Launches Agent DLP for Autonomous Agents**

**What launched:** **Agent DLP**, a runtime data loss prevention capability for autonomous AI agents, integrated into the **ArgusAI platform**. Sits inline at the agent gateway, bidirectionally inspecting MCP tool calls and responses in real time.

**Key features:**
- **Bidirectional inspection:** Monitors what agents send to tools AND what sensitive data returns
- **Native integration:** Works with AWS AgentCore, LiteLLM, and other agent gateways
- **Real-time blocking:** Prevents sensitive data leakage before it leaves the environment
- **Audit trails:** Full visibility into agent data access patterns

**Why it matters:** CISOs can now see and regulate what agents send to external tools and what confidential data comes back, making high-value autonomous workflows (report generation, third-party updates) approvable without losing data visibility.

**Source:** [AI Agent Store](https://aiagentstore.ai/ai-agent-news/this-week)
