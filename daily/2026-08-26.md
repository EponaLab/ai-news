## 🔥 Key Highlights

### 1. **Okta Launches Agent SSO: AI Agents as First-Class Identities**

Okta announced **Agent SSO**, bringing AI agents into its Universal Directory as managed identities with the same access controls used for human employees. The platform uses Okta's Cross App Access protocol to give agents short-lived tokens instead of hard-coded credentials.

**Why it matters:** As teams deploy agents acting across SaaS tools and internal systems, centralized identity management becomes essential to avoid sprawling API keys and shadow accounts. Security teams can now answer "where agents run, what they can reach, and who approved that access" within existing IAM frameworks.

**Implementation note:** Agent SSO provides task-scoped, short-lived tokens with policy-based access controls, automatic audit trails, and revocation capabilities—addressing the 24% of MCP servers that currently ship with no authentication at all.

### 4. **OpenAI's ChatGPT Work Adoption Challenge: 98% Internal vs. <1% Consumer Use**

An in-depth TechCrunch report reveals the massive adoption gap for OpenAI's ChatGPT Work (formerly Codex): **98% of OpenAI employees** use the agentic tool, but only **17% of organizational subscribers** and **less than 1% of individual subscribers** have adopted it.

**Key insights from OpenAI engineers:**
- Making AI intuitive for non-engineers requires extensive "harness" engineering—software wrapping around models that decides what information they see and which tools they can use
- Early versions were "actively hostile" to non-technical users (showing code diffs and technical readouts)
- Most workflows aren't as measurable as code—no clear pass/fail evaluation
- Cost subsidy is massive: $65 in token usage over 4 days on a $20/month plan

**Product philosophy clash:** Internal debate over whether buttons/UI are needed vs. just asking the model directly. Team argues "discoverability matters in this phase" even if power users don't need it.

**Competitive pressure:** Claude Code defined the market by focusing on conversational back-and-forth vs. OpenAI's initial "AGI-pilled" autonomous approach. OpenAI eventually followed suit, adding more user interaction points.

**The bitter lesson:** OpenAI engineers believe better general models matter more than domain-specific harness engineering—"the next model is going to come out in a couple of months and make that obsolete."

## 💡 Insights & Analysis

### **The Identity Management Inflection Point**

Today's Okta Agent SSO launch marks a critical infrastructure milestone: **AI agents as first-class identities** within enterprise IAM systems. This addresses the 24% of MCP servers shipping with no authentication—a security gap that has prevented broader production deployment.

**Why this matters now:**
1. Agents are no longer experiments—80.8% of engineers use them daily
2. Security teams need centralized visibility and control as agent count scales
3. Short-lived, task-scoped tokens prevent credential sprawl and shadow accounts
4. Existing IAM policies can extend to agents without rebuilding infrastructure

**Prediction:** Within 12 months, agent identity management will be a prerequisite for enterprise agent deployment, similar to how SSO became mandatory for SaaS adoption. Vendors without identity integration will be excluded from procurement.

---

### **The 98% to 1% Problem: Why Agent Adoption Stalls**

OpenAI's internal vs. external adoption gap reveals the fundamental challenge of agentic AI: **what works for technical early adopters doesn't translate to mainstream users**.

**Root causes:**
1. **Discoverability:** Non-technical users don't know what to ask or how to evaluate results
2. **Measurability:** Unlike code (pass/fail), most knowledge work lacks clear success metrics
3. **Cost subsidy:** $65 token usage on $20 plans is unsustainable at scale
4. **Permission complexity:** Configuring access across tools requires technical understanding
5. **Trust gap:** Users unsure when to rely on agent output vs. verify manually

**The harness engineering challenge:** Building interfaces that guide non-experts without limiting power users—the classic "expert vs. beginner" UX problem amplified by probabilistic AI behavior.

**Watch for:** Companies that solve the discoverability and trust problems (through better UX, evaluation frameworks, or bounded autonomy) will capture the 99% who haven't adopted agents yet.

### **The Great Agent Search Infrastructure Race**

Keenable's $26M raise for agent-optimized web search reveals a critical infrastructure gap: **generic search tools weren't built for how agents retrieve and reason**.

**Agent search requirements differ from human search:**
1. **Latency-sensitive:** Agents in reasoning loops can't wait for slow searches
2. **Citation-critical:** Agents need verifiable sources for downstream decisions
3. **Volume-intensive:** Agents may search dozens of times per task
4. **Context-aware:** Results must integrate with agent's current task state

**Strategic implications:**
- Web search becomes infrastructure layer, not just a tool
- Agent performance depends on search stack quality (latency, relevance, cost)
- Winners provide MCP-compatible APIs with predictable pricing

**Prediction:** By 2027, agent search infrastructure will be as critical as vector databases are today. Platforms that lack optimized search will struggle with agent task completion rates.
